## Interpretation

The extracted Duesseldorf frequencies use original STR allele labels. The Amarna scripts currently use diagram colour labels. Several Paper priors match Duesseldorf frequencies at a different allele label than the stored `paper_length`; therefore this file is an audited source dataset, not yet a drop-in replacement for the operational color-coded founder scenarios. For Locus3/D2S1338 the selected population is the paper-specified Israeli fallback, not Egypt.
